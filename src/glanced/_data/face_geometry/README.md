`geometry_pipeline_metadata_landmarks.binarypb` is copied byte-for-byte out of
Google's MediaPipe `face_landmarker.task` (float16/1, sha256
64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff). It holds the
canonical face mesh and the Procrustes landmark weights that MediaPipe's
geometry pipeline uses to compute the facial transformation matrix.
